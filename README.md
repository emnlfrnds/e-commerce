# E-Commerce | SENAI

Esse projeto foi gerado usando [Angular CLI](https://github.com/angular/angular-cli) versão 22.0.4.

## Servidor de Desenvolvimento

Para começar um servidor de desenvolvimento local, rode:

```bash
ng serve
```

Enquanto o servidor estiver ligado, abra seu navegador e navegue para `http://localhost:4200/`. A aplicação atualizará automaticamente a cada mudança salva nos arquivos.

## Estruturar Código

Angular CLI inclui ferramentas poderosas de criação de código. Para gerar um novo componente, rode:

```bash
ng generate component component-name
```

Para uma lista completa de ferramentas disponíveis, rode:

```bash
ng generate --help
```

## Build

Para buildar o projeto, rode:

```bash
ng build
```

Isso vai compilar seu projeto e armazenar os artefatos de build na pasta `dist/`. Por padrão, o build de produção otimiza sua aplicação para desempenho e velocidade.

## Executando teste de unidade

Para executar testes de unidade com o [Vitest](https://vitest.dev/) test runner, use o comando a seguir:

```bash
ng test
```

## Executando testes de e2e

Para testes de ponta a ponta (e2e), execute:

```bash
ng e2e
```

O Angular CLI não vem com um framework de teste de ponta a ponta por padrão. Você pode escolher um que se encaixe nas suas necessidades.
